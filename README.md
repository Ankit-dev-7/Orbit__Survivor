Orbit Survivor

 A fast-paced sci-fi survival game where you pilot a lone spacecraft trapped in a collapsing star system. Use planetary gravity to slingshot through space, dodge deadly hazards, gather resources, and survive as long as possible.

 In order to play just download the file Game .. Open the Godot engine and just open the file inside Game called project.godot 

 Or in order to play demo online just click this link :  https://ankit-7.itch.io/orbit-survivor
